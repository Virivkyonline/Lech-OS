# Logo LECH OS

`lech-os-logo-z-tapety.png` – logo „LECH OS“ s oblúkom, vyrezané z tapety (`branding/tapety/tapeta-logo-941x1672.png`)
a oddelené od oblohy podľa jasu (priehľadné pozadie, 387 × 137 px). Používa ho animácia pri štarte
(`tools/make_bootanimation.py`). Je malé – na ostrú animáciu a tlač treba logo vo vysokom rozlíšení (aspoň 2000 px
šírka, PNG s priehľadnosťou alebo SVG) – potom ho stačí uložiť sem a zostaviť animáciu znova.
